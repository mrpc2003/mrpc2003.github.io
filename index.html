다중 이미지 VLM의 구분자 스케일링 재현

ICLR 2026 논문 독립 재현|Machine Intelligence Lab|2026.07

+4.19%pMuirBench 2,600문항|37.00% → 41.19%

Qwen2.5-VL-3B의 구분자 은닉 상태 스케일링을 원저자 공개 코드를 기반으로 독립 재현하고, 고해상도 비전 어텐션의 메모리 문제에 대응하는 블록 단위 SDPA 평가 경로를 구현했습니다. MuirBench 공개 벤치마크 전체에서 기본 설정 대비 개입 설정의 정확도가 오르는 경향을 부분 재현했습니다.

Code & Report·Paper

Details
확인하려던 문제
이미지 사이 구분자 토큰의 은닉 상태를 키우는 개입이 다중 이미지 이해 정확도를 높인다는 논문 결과가 다른 실행 환경에서도 나타나는지 확인했습니다.
본인 역할
원저자 공개 구현(MYMY-young/DelimScaling)으로 실행 환경을 구성하고, 저장소의 4-process FlashAttention-2 경로 대신 블록 단위 비전 SDPA 평가 경로를 구현했습니다.
비교 조건
Qwen2.5-VL-3B, 개입 레이어 0–3, 스케일 λ=8, MuirBench 전체 2,600문항, 2× RTX PRO 6000 Blackwell.

SO-ARM 101 기반 VLA 체스 로봇

AIM ChessRobot|AIM 동아리 3인 팀|2026

3인 팀으로 SO-ARM 101 로봇팔과 Jetson Orin Nano를 연결하고 텔레오퍼레이션으로 시연 데이터를 수집했습니다. 원격 Policy Server의 SmolVLA(450M)가 계산한 action chunk를 Jetson이 비동기로 받아 안전 게이트를 거쳐 실행하는 구조를 만들었고, 실물에서 SmolVLA 정책으로 체스말 1개를 집는 데 성공했습니다.

Details
확인하려던 문제
엣지 디바이스(Jetson)와 원격 정책 서버로 나눈 구성에서 VLA 정책이 실물 체스말을 집고 옮길 수 있는지 확인하는 것이 목표입니다. 어떤 수를 둘지는 python-chess·Stockfish가 맡고, VLA는 집기·옮기기 조작만 담당하도록 역할을 나눴습니다.
구성
SO-ARM 101 + Jetson Orin Nano 8GB, 손목 카메라 마운트 직접 설계. Jetson은 관측 수집·action queue·안전 게이트(clamp, timeout, stale action 무시, E-stop)를 맡고, Policy Server는 LeRobot·SmolVLA로 action chunk를 계산합니다. top-view 호모그래피로 8×8 보드 점유를 인식하고 python-chess로 합법수를 검증합니다.
진행 범위
캘리브레이션, 텔레오퍼레이션 시연 데이터 수집, 정책 서버–Jetson 실행 구조 구성 후 실물에서 SmolVLA 정책으로 체스말 1개 집기에 성공했습니다.
한계
체스 한 수 전체(집기–이동–놓기)의 자동 실행과 반복 성공률 측정은 아직 진행 전입니다. 코드는 비공개 팀 자료라 링크를 싣지 않습니다.

종이접기·휴머노이드 로봇의 실기 평가

IROS 2026 Robotic Origami Challenge|제21회 국제로봇콘테스트|2026.06 – 2026.11

동상제21회 국제로봇콘테스트(IRC) · 팀 수상

두 로봇 대회에서 학습·제출 기록과 실기 로그를 정리하고, 영상과 대조해 실패가 발생한 단계를 분류했습니다. 제21회 국제로봇콘테스트(IRC)에서는 팀이 동상을 받았습니다.

IROS Challenge

Details
IROS 2026 · 팀 OriMo
2026.06 – 2026.10. Sharpa 양팔 로봇으로 종이를 접는 국제 챌린지입니다. 팀은 정책 증류로 양팔 로봇의 행동 명령을 생성할 때 필요한 추론 반복을 10회에서 6회로 줄였습니다. 저는 서버별 학습 기록·체크포인트와 실제 제출본의 대응 관계를 정리하고, 원격 실기 로그를 영상과 대조해 실패 발생 단계를 분류했습니다. 추론 명령이 제시간에 생성되고도 접촉 직전 접근 구간에서 멈추는 사례를 확인했습니다.
IRC 2026 · 팀 국민대학교 로봇국
2026.11. 마트 환경 기반 휴머노이드 로봇 경진대회(산업통상부·대구광역시 주최, 한국로봇산업진흥원 주관)입니다. 팀은 Isaac Sim으로 예선을 치렀습니다. 본선에서는 AI Worker 실물 로봇의 바구니 집기에 π0.5 VLA를 사용했고, 대회에서 동상을 받았습니다. 저는 본선 현장 런타임 릴리스를 보존하고, 시도별로 파지·주행이 멈춘 단계를 대조했습니다.
한계
로그와 영상을 대조해 실패가 발생한 구간을 분류한 결과이며, 특정 모델 구성이 실패 원인임을 입증한 개입 실험은 아닙니다. 대회 비공개 자료는 싣지 않습니다.
