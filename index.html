01

소개

오프라인 예측 오차나 분류 정확도가 비슷하더라도, 실제 하드웨어와 로봇 위에서는 실행 시간과 작업 완수 여부가 크게 갈리는 현상을 측정으로 확인해 왔습니다.

양팔 로봇 종이접기 국제 챌린지(IROS 2026)와 마트 환경 휴머노이드 경진대회에서 팀의 VLA 정책이 실물 로봇 위에서 멈춘 지점을 로그와 영상으로 시도 단위로 추적했습니다. 연구실과 수업에서는 Qwen2.5-VL-3B 구분자 토큰 은닉 상태 스케일링(2× RTX PRO 6000), 구조적 가지치기·4비트 양자화(PTQ/QAT), ViT·Swin·ResNet 보정·재현성 감사, GPT-2 124M 분산 학습(DDP), im2col 타일링과 Systolic Array 시뮬레이터를 직접 구현하고 검증했습니다.

초등 정보과학영재학급의 Scratch에서 시작해 고교 FTC 로봇팀 '메인보드'(Rising Star Award), 공군 항공교통 복무(2023.05–2025.02)를 거쳐 현재 국민대학교 Machine Intelligence Lab 학부연구생으로 활동하고 있습니다.

CIFAR-100에서 ResNet-18의 비구조적·구조적 가지치기와 MobileNetV2 저비트 양자화(PTQ·QAT)가 정확도, CPU 단일 스레드 지연, GPU(RTX PRO 6000) FP16 배치 처리량에 미치는 영향을 측정했습니다.
